# 麻将记分全流程设计 V3

本版根据用户最新反馈重新制作：项目原有视觉风格是基准。此前 V1 的绿桌面、V2 的新插画方向不作为本版视觉规范。

## 保留的项目风格

- 直接以 `miniprogram/assets/illustrations/tabletop-atlas.png` 为生成参考：绿边白色麻将牌、红「中」、红黑花色扑克牌、蓝色骰子、蓝边加减分牌、珊瑚橙棋子，以及原有账单和气泡图形。
- 延续原有圆润立体、柔和高光和阴影。麻将和扑克牌的造型、厚度、配色均以项目素材为准。
- 界面保留浅灰蓝背景 `#f5f7fa`、白色圆角卡片、主蓝 `#2d5bff`、深色文字 `#172139`、次要文字 `#7b879c`、珊瑚橙 `#ff765e`。
- 首页两张场景卡片继续采用左侧文字、右侧插画；麻将浅薄荷绿底，炸金花浅桃色底。顶部保留项目通用棋牌组合插画，删除整个记分规则模块。
- 大型功能插画与项目原有立体素材统一；编辑、扫码、键盘、复制、关闭等小操作图标保持圆角线性、统一粗细与蓝灰配色。图标的体量、颜色与页面用途一致。
- 等待房间沿用当前双列座位卡片，积分榜沿用纵向列表，不替换为绿色实物麻将桌。

## 轻量互动提案

- 入口卡片触按微缩约 120ms；立体插画只做短暂跟随反馈，不持续漂浮。
- 新牌友加入后，只让对应座位卡片淡入、轻弹约 240ms，保留原来的网格布局。
- 服务端确认给分成功后，加减分图标和对勾短暂轻弹约 280ms，分数短暂过渡；不让动画覆盖输入区、阻止下一次输入或延迟真实分数显示。
- 邀请二维码以普通白卡轻放大约 180ms，二维码本体保留静区，不做变形和复杂特效。
- 结算结果使用原账单插画，约 250ms 淡入。结算确认中的金额、不可修改提示和确认按钮保持清晰稳定。
- 战绩卡片淡入约 180ms；减少动态或低性能设备直接显示最终状态。

## 业务约束

手动记分与多人批量给分规则不变。创建房间保留名称、密码的原位编辑，昵称仍为普通输入框。手动加入完整保留房间码、密码、昵称三项；扫码和邀请只确认昵称。游客继续可用，登录后可追溯关联本局战绩。

创建、等人和实时记分阶段不展示金额。房主散场时设置每分金额，默认 1 元／分。最终结果保留输赢和转账建议，未新增实际付款、聊天、自动番型计算或战绩成就功能。
