FunBox 功能建议与问题反馈一体化 · 用户端设计

搜索空态补上反馈入口，问题与建议同一套表单、状态与消息通知，全部使用真实数据。

2026-08-04 一期交付 真实数据

问题

  • 搜索无结果时只有清空和查看全部，需求无处表达。
  • 功能建议与问题反馈分成两套心智，维护成本高。
  • 管理员处理后结果无法回到用户。

方案

  • 空态新增“去反馈”整行入口，关键词自动带入。
  • 反馈中心统一“问题反馈 / 功能建议”。
  • 消息中心新增“系统通知”页签承载处理结果。
  • 未读数、状态、回复全部来自服务端。

真实数据红线

  • 不写死任何反馈、回复、状态或未读数。
  • 不向生产库 seed 演示数据。
  • 空态出现与否由真实搜索结果决定。
  • 设计图为真实上传文件，私有鉴权读取。

设计要点

1

空态保留两个主按钮，反馈入口独立成行，窄屏不拥挤。

2

关键词预填“功能名称”，可编辑，不视为假数据。

3

问题与建议共用表单、状态和消息通道。

4

系统通知未读红点与消息 Tab 角标联动。

设计稿中的昵称、时间和回复内容仅作版式示意；交付后页面只展示真实数据库与真实 API 返回的数据。
