双色球计划
实验室

把文档里的“选期数、三套算法、n-1 期推 n 期、逐期奖金对比、Excel 导出”做成独立工具，不修改现有概率参考。

产品目标

  • 首页 / 工具列表只保留一个“双色球”入口
  • 点击后进入二级页，选择概率参考或计划实验室
  • 可选 100 / 200 / 400 / 1000 期官方历史数据
  • 低频优先、时间加权、正态拟合三套算法
  • 回测每期中奖金额与买入成本，计算数学期望
  • 一、二等奖浮动金额用官方数据，固定奖按规则
  • 一键导出 Excel 可打开的 CSV 明细

关键原则

  • 回测只用目标期之前的数据，避免未来数据泄漏
  • 单独展示“剔除头奖后收益”，防止单期大奖误导判断
  • 始终提示开奖为随机事件，不出现“必中 / 稳赢”

设计方向

A
参数优先设置区在最上方，结果区紧随其后
B
收益导向先看总投入 / 总奖金 / 每注期望
C
明细可查逐期预测、开奖、奖金和盈亏都可导出
