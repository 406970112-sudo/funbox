# 首页游戏卡片玩法图标设计

## 目标

重做 FunBox 首页“放松一下”区域的四款游戏图标，使用户不看标题也能快速识别贪吃蛇、五子棋、俄罗斯方块和打砖块，同时保持现有首页轻盈、克制的卡片风格。

本次只调整游戏卡片顶部视觉区，不改变卡片尺寸、标题、分类文字、游戏顺序、路由或点击范围。

## 视觉方向

采用“微缩玩法场景”方向。每个图标都在统一的 `64 × 48` 画布中呈现一段最具代表性的玩法瞬间：

- 贪吃蛇：转折中的分节蛇身，蛇头朝向一枚红色果实。
- 五子棋：棋盘交叉线与黑白棋子，棋子形成可读的攻防走势。
- 俄罗斯方块：多色方块堆叠，并保留一个待填补的缺口。
- 打砖块：上方砖墙、反弹小球、运动轨迹和底部挡板。

四款游戏沿用当前的绿色、棕橙、蓝色和珊瑚红身份色。视觉区使用对应强调色的低透明度背景，主体图形可加入少量必要的辅助色，但不扩展成复杂插画。

独立的圆形播放图标移除。卡片整体已有明确的可点击形态和按压反馈，额外播放按钮会挤压场景并削弱玩法表达。

## 组件结构

新增专用的 `GameArtwork` 组件，由游戏 ID 选择对应场景。组件使用 `react-native-svg` 绘制，确保 Web、iOS 和 Android 共享同一套几何图形，并能在不同像素密度下保持清晰。

`GameTile` 继续负责卡片结构、主题颜色、标题、分类和点击行为，只把当前的通用图标拼装替换为 `GameArtwork`。未来出现未支持的游戏 ID 时，组件显示中性的游戏手柄图标作为安全回退，不影响首页渲染。

场景组件不读取路由或游戏状态，也不维护交互状态。它只接收游戏 ID 和强调色，保持职责单一，便于独立检查。

## 响应式与主题

视觉画布在当前 `58` 高度的顶部区域内居中缩放，不改变卡片宽度分配。图形使用固定 `viewBox` 和响应式尺寸，在四列桌面布局与窄屏布局中都不会改变卡片几何或发生裁切。

浅色模式使用低透明度身份色作为背景；深色模式继续由现有主题表面色和身份色组合提供对比。白色或深色棋子、挡板等中性色应由主题感知颜色控制，避免深色模式下消失。

## 交互与无障碍

整张游戏卡片继续使用 `Pressable`，保留现有点击、路由和按压反馈。场景 SVG 是装饰性内容，不重复朗读；卡片本身继续提供游戏名称和开始游戏的无障碍提示。

移除播放按钮后不减少可点击区域，也不引入独立焦点。键盘和触摸操作路径保持不变。

## 错误处理

- 未识别的游戏 ID 使用通用游戏手柄回退图标。
- 场景组件不依赖图片加载或网络资源，因此不会出现资源请求失败。
- 图形颜色通过显式属性传入，缺少强调色时使用应用主题的默认强调色。

## 验收与测试

- 四款游戏在不看标题时仍可通过玩法场景区分。
- 打砖块不再错误复用贪吃蛇图标。
- 首页四张游戏卡片的高度、间距、标题和分类文字与改造前一致。
- 浅色和深色主题下，棋盘线、棋子、蛇身、果实、方块、砖块、小球和挡板均清晰可见。
- 桌面宽度与窄屏宽度下无裁切、重叠或卡片跳动。
- 运行前端 lint、相关单元测试和生产构建。
- 使用浏览器分别检查桌面与移动视口，并确认四张卡片均可点击进入对应游戏。
