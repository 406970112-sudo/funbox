# 最近使用真实数据设计

## 目标

将“我的 > 最近使用”从固定 mock 数据改为用户真实使用记录。工具和游戏都计入，按最近一次使用时间倒序展示，最多显示 3 条。

## 数据边界

- 用户进入一个存在且当前可用的工具或游戏详情页时，记录一次使用。
- 同一个项目重复进入时只保留一条记录，并移动到列表首位。
- 记录保存在当前设备：Web 使用 `localStorage`，原生端使用 `SecureStore`。
- 本期不新增服务端表或跨设备同步。
- 损坏、过期或无法识别的持久化数据会被忽略，不影响页面打开。

## 组件与数据流

1. 纯数据模块负责校验记录、去重、排序和截断到 3 条。
2. 平台存储模块负责读取和写入 JSON，不包含界面逻辑。
3. 工具与游戏统一详情入口在确认项目有效后记录使用，因此首页、工具页、“最近使用”回跳和深链接都不会漏记。
4. “我的”页面获得焦点时重新读取记录，映射到当前工具或游戏元数据后渲染；已不可见或不可用的项目不展示。
5. 没有真实记录时显示明确的空状态，不再使用演示数据兜底。

## 测试

- 单元测试先覆盖新增记录、重复记录上浮、第四条挤出最旧记录、无效持久化数据过滤。
- 运行前端 lint 和相关单元测试。
- 使用内置浏览器依次进入 4 个不同项目，再打开“我的”，确认只展示最新 3 条且顺序正确；刷新页面后确认记录仍存在，并检查控制台无相关错误。
