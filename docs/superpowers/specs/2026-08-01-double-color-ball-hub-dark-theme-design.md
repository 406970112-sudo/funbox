# 双色球入口深色模式设计

## 目标

修复双色球二级入口中 V2 与 V1 实验室卡片在深色模式下仍显示浅色背景的问题，并移除三张卡片右侧的全部状态标签。

## 视觉方案

- 概率参考卡片：浅色模式保持白色；深色模式使用中性深灰表面。
- 计划实验室 V2：浅色模式保持淡蓝；深色模式使用压暗蓝色表面和边框。
- 计划实验室 V1：浅色模式保持淡金；深色模式使用压暗金色表面和边框。
- 三张卡片的图标底色随主题切换，保留珊瑚红、蓝色、金色的识别色。
- “已有功能”“新功能”“经典版”三个标签全部移除，标题与副标题获得更多水平空间。
- 操作按钮继续保留各自强调色，确保入口层级和点击目标清晰。

## 实现边界

- 只修改双色球二级入口组件及其针对性测试。
- 不改变三个入口的路由、文案、交互和业务逻辑。
- 不调整全局主题 token，避免影响其它页面。

## 验证

- 自动测试覆盖浅色与深色的三套卡片配色，并验证卡片不再生成标签。
- 使用 Codex 内置浏览器检查桌面与移动视口的深色页面。
- 检查页面内容、控制台、遮挡、溢出、卡片可读性和至少一个入口跳转。
