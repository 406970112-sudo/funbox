# 打砖块游戏设计

## 目标

在 FunBox 首页的“放松一下”区域新增一款可直接游玩的打砖块游戏。游戏延续现有俄罗斯方块的移动端视觉与页面结构，支持触摸、鼠标和键盘操作，并在 Web、iOS 与 Android 上共享同一套核心逻辑。

首发体验强调三件事：球路清楚、单指控制直接、连续破砖有节奏。用户进入页面后无需选择模式即可开始，失败或通关后可立即再来一局。

## 产品范围

- 经典挡板反弹与砖块碰撞。
- 三条生命，掉球后保留当前关卡并重新发球。
- 关卡递增，清空砖块后进入下一关并提高球速。
- 连击计数与得分倍率。
- 三种掉落道具：穿透、多球、扩板。
- 暂停、继续、重新开始与本局结束面板。
- 本地保存历史最高分。
- 移动端拖动挡板和点击发球；Web 端额外支持鼠标、方向键、空格与 Escape。
- 无障碍标签、减少动态效果兼容和轻量触觉反馈。

不包含排行榜、账号云同步、付费道具、关卡地图、联网对战或后端接口。

## 页面设计

页面采用已确认的高保真设计稿：浅蓝外层画布、白色移动端页面、墨蓝游戏场、蓝色主操作色，以及薄荷绿、珊瑚橙、明黄和青色砖块。

顶部应用栏包含返回、标题和暂停按钮。其下使用固定高度数据条展示得分、关卡和生命。游戏场保持稳定的纵向比例，砖块、球、道具与挡板全部在同一画布内渲染，连击与限时道具状态贴边显示，不遮挡主要球路。底部控制区提供宽大的拖动区域和独立发球按钮。

暂停与结束状态使用底部面板，保留变暗的局内画面作为上下文，并展示本局得分、最高连击和历史最佳。

## 架构

### 物理会话

新增独立的 `brick-breaker-engine` 模块，使用 `matter-js` 管理球、挡板、边界、砖块和掉落道具的碰撞。模块通过明确的命令接口处理开始、暂停、继续、重开、移动挡板和固定时间步推进，并输出适合界面渲染的只读快照。

物理模块不依赖 React Native、路由或本地存储。每个更新周期限制最大时间跨度，并拆分为稳定的小步长，避免后台恢复或低帧率时发生穿砖和异常加速。

### 玩法规则

规则层维护关卡、生命、得分、连击、道具时效和会话阶段。普通砖一击破坏，加固砖需要两击。每次有效破砖增加基础分，连续命中提高连击；掉球会重置连击。

砖块被破坏时有小概率掉落道具：

- 穿透：球在限时内穿过砖块，不因砖块碰撞反弹。
- 多球：从主球速度方向生成额外球，所有球丢失时才扣除生命。
- 扩板：限时增加挡板宽度，结束时平滑恢复。

清空当前关卡后生成下一组确定性砖块布局，提升基础速度并保留生命与累计得分。生命归零进入结束状态。

### 界面组件

新增 `brick-breaker-game-screen`，负责页面布局、动画、输入映射、触觉反馈和把物理快照渲染为 React Native `View`。游戏状态更新由单一帧循环驱动，离开页面时必须停止循环并释放物理世界。

最高分存储沿用俄罗斯方块的本地存储模式，Web 使用 `localStorage`，原生端使用安全的文件存储。存储失败不阻止游戏运行。

### 应用接入

在游戏类型和首页游戏数据中注册 `brick-breaker`，将其标记为可玩。游戏详情路由根据该 ID 渲染新页面。首页仍只展示固定数量的可玩游戏时，调整展示数量以确保新游戏可见，同时保持现有卡片结构。

## 输入与状态流

1. 页面加载并创建关卡，阶段为“待发球”。
2. 用户拖动控制区或移动鼠标，挡板跟随并限制在场地范围内。
3. 用户点击发球按钮或按空格，主球从挡板上方释放。
4. 帧循环推进物理世界并输出砖块、球、道具、得分和状态快照。
5. 暂停时停止物理推进，但保留所有实体位置；继续后恢复。
6. 所有球越过底部时扣除生命，并将主球重新停靠在挡板上；生命归零时显示结束面板。
7. 清空砖块时短暂显示过关反馈，再生成下一关。

## 错误处理

- 物理步长会被限制，页面从后台恢复时不会一次推进过长时间。
- 存储读写失败时回退到内存最高分，不弹出阻断提示。
- 页面尺寸变化时重新计算显示比例，但保留物理世界的归一化坐标。
- 非法或缺失的游戏 ID 继续使用现有占位页，不影响其他游戏。
- 卸载页面时清理计时器、动画和物理事件监听，避免后台继续计分。

## 测试与验收

单元测试覆盖：初始状态、发球、挡板边界、砖块伤害、得分与连击、掉球扣命、多球判定、三种道具、暂停不推进、清关升级和结束状态。

静态验证运行新增测试、现有游戏测试与前端 lint。渲染验收使用 Codex 内置浏览器，检查桌面和窄屏视口：页面完整、游戏场不空白、数据和控制不重叠、暂停面板可见、键盘与按钮产生状态变化、控制台无相关错误。

## 成功标准

- 用户能从首页进入打砖块并完成一局完整流程。
- 触摸/鼠标拖动和键盘控制都能稳定移动挡板。
- 高速球不会明显穿过砖块或挡板。
- 暂停、掉球、过关与游戏结束状态可恢复或重开。
- 桌面与手机宽度下没有遮挡、溢出或不可点击控件。
