# 精选功能轮播往返顺序设计

## 目标

将首页“精选功能”自动轮动从单向循环 `A -> B -> C -> D -> A` 调整为端点不重复停留的往返轮动：

`A -> B -> C -> D -> C -> B -> A -> B -> ...`

手动滑动、分页按钮、减少动态效果设置和应用前后台暂停行为保持不变。

## 实现方案

新增一个无 UI 依赖的纯函数，根据当前索引、当前方向和可见卡片数量返回下一索引与下一方向。轮播组件使用一个方向引用保存自动播放方向：

- 位于最后一张卡片时，下一步向左；
- 位于第一张卡片时，下一步向右；
- 位于中间卡片时，沿当前方向继续；
- 少于两张卡片时保持当前索引，不触发越界。

自动播放定时器继续负责更新当前索引、分页状态和滚动偏移，只把原来的取模递增替换为纯函数结果。这样不会复制卡片，也不会改变分页数量、卡片键或无障碍语义。

## 手动交互

手动滑动或点击分页按钮仍直接设置当前索引。选择首张卡片后，下一次自动播放向右；选择末张卡片后，下一次自动播放向左；选择中间卡片时保留当前自动播放方向，使轮播继续自然运动。

## 测试与验证

先为纯函数编写失败测试，覆盖：

- 四张卡片从首张开始产生 `A, B, C, D, C, B, A, B`；
- 两张卡片在两端之间往返；
- 零张或一张卡片不会产生越界索引。

实现后运行聚焦测试、前端类型检查和 lint。随后启动 Expo Web，并使用 Codex 内置浏览器检查首页身份、有效内容、错误覆盖层、控制台告警、分页状态与实际自动轮动顺序，同时保留截图证据。
