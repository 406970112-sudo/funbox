# 麻将房交互动效

按本聊天已确认的两张设计图实施：蓝白色、陶瓷麻将牌、轻桌游感；加入页包含扫码首页、手动加入抽屉、邀请昵称确认。入座落牌、四牌合拢开局、增分上浮、减分下落、积分榜平滑换位、结算账单展开。补充复制房间码变勾、重连提示。

保留已有规则：自动入座、至少两人开局、本人给其他人记分、散场才确定金额、结算前核对并二次确认。后台确认成功才显示成功动效。多人同步、重复快照不能重复播放；进入历史房间和后台恢复不回放历史事件；隐藏页面取消计时器。动效可关闭，最终分数始终以服务端快照为准。

采用原生 WXML/WXSS 和少量 JS 状态驱动，复用现有插画，不引入依赖。不增加音效或默认震动，不改后端和炸金花；通用记分维持原流程。重点动效约 120–900 ms，反馈浮层不拦截操作。

## 视觉一致性修正

用户指出新增 CSS 麻将牌与原有素材不一致。扫码装饰改为直接复用 `tabletop-atlas.png` 的麻将图；座位/榜单标识恢复原有样式；入座成功复用原有结算插画。开局使用匹配原材质的新四风牌图集，牌面字已绘制在图片内，不再用系统字体模拟实体麻将。

新素材：`miniprogram/assets/illustrations/mahjong-winds-atlas.png`。使用内置 imagegen，以现有 `tabletop-atlas.png` 为风格参照生成透明 2×2 图集，随后缩至小程序展示所需分辨率。

生成提示词要点：严格匹配原图顶部中央麻将的立体材质、光照与相机角度；四个等大透明象限分别为東、南、西、北；厚实暖白陶瓷牌身、圆润倒角、深绿色侧边；字形为深绿立体釉彩笔画，不能用扁平蓝色 UI 字体；四张牌比例和基线一致，无额外元素。
