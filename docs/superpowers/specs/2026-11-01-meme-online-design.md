# 联网搜图增量设计

用户于2026-11-01已选择并授权方向：保留分类图库，新增多源联网搜图，复用收藏/预览/保存。

上游 https://github.com/o98k-ok/meme 是Go编写的stdio MCP聚合搜索器，README列出斗图啦、胖哒、搜狗、趣斗图、斗图API与抖音，并声明MIT；不包含全库或每日热榜。其internal包不能直接从当前module导入。选择把source适配器纳入现有Go服务并按现有标准改造，避免多进程MCP协议给小程序调用带来额外复杂度。另一可选方案为独立MCP sidecar，增加部署/进程协议成本，因此未采用。

界面采用“图库 / 联网搜图”模式，关键词、全部/指定来源、来源状态、部分失败/重试、真实分页，点图沿用详情收藏保存。原图库、分类、站内榜单和首页保持语义不变，首页不加藏图快捷入口。公网数据源不保证长期稳定，Cookie只由服务端配置。无凭据来源先接入并实测；抖音未配置时明确禁用。安全、API、分工及验收见 ../plans/2026-11-01-meme-online.md。

用户后续明确范围：仅小程序端及所需后端接口；Web 不接入，先前本轮 frontend 改动已全部撤回。
