# FunBox 微信一键注册／登录

用户已批准本聊天中的效果图与实施方案。沿用现有蓝白背景、棋牌插画、圆角卡片，微信绿色主按钮；默认展示微信入口，手机号密码表单作为次级入口，游客可返回继续开局。仅在主动登录或账号功能时打开页面，不在启动时调用微信登录。

个人主体通过 wx.login 的 code 由现有 Go 后端调用 code2Session。首次事务内建普通用户与微信绑定，以后复用 user ID 与现有 JWT。新用户默认昵称“微信牌友”，无需手机号、密码和密保；内部保留不可登录的随机账号标识，与公开手机号区分。AppSecret、session_key、OpenID 不下发。

绑定按 (AppID, OpenID) 唯一，同一 AppID 下每个用户只能绑定一个微信。老用户先用现有密码登录，再从个人设置主动绑定微信，冲突时拒绝，不自动合并数据或覆盖身份。绑定保持原用户、昵称、权限、密码与业务数据。

协议默认未选；两个协议入口展示基于现有实现的数据用途与使用说明；拒绝不会阻止游客。登录中禁用重复提交，失败可重试；退出、页面卸载或换号后迟到响应不得恢复登录。成功返回来源页面，兼容 tab 页面。资料完善复用个人设置。

部署复用 WECHAT_MINIPROGRAM_APP_ID / APP_SECRET。本地只检查配置存在性，不显示密钥，不重置配置，不部署或发布。保留本次之前已有通用记分改动。
