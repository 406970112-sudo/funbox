## Shared API Contract

所有路径以 `/api/v1` 为前缀，错误使用现有 `{error,detail?}`。时间为 RFC3339 字符串，榜单日期 YYYY-MM-DD / Asia/Shanghai。

```ts
type Category = {id:string; title:string; originalTitle?:string; count:number; coverUrl:string; group:string};
type Image = {id:string; title:string; label:string; url:string; thumbnailUrl:string; width:number; height:number; animated:boolean; bytes:number; format:string; categories:{id:string;title:string}[]; favorite?:boolean};
type Page = {items:Image[]; nextCursor:string; total:number; version?:string; source?:{name:string;url:string;syncedAt:string}};
```

- `GET /memes/categories?q=&group=` → `{items:Category[],total:number,source?:...}`。
- `GET /memes?q=&category=&animated=true|false&sort=default|newest&cursor=&limit=36` → Page。q 支持现有标签和分类；不承诺无标签语义搜索。非法 cursor 返回 400，快照已更新可返回 409，客户端清 cursor 重载。
- `GET /memes/{id}` → `{image:Image,related:Image[]}`。
- `GET /memes/rankings?period=day|week|all&date=` → `{items:(Image & {rank?:number;score?:number})[],mode:'ranking'|'curated',period,date,updatedAt,algorithmVersion,dataSince,isFinal,notice?:string}`。
- `GET /memes/ranking-dates` → `{dates:string[],nextCursor:string}`。
- `GET /memes/favorites?cursor=&limit=36` → Page，JWT；`PUT/DELETE /memes/{id}/favorite` → `{favorite:boolean}`，JWT，幂等。
- `POST /memes/events` → `{accepted:boolean}`，body `{imageId,type:'view'|'save',eventId,anonymousId}`；token 可选，客户端 UUID/随机安装标识持久保存。收藏分数仅后端从 PUT 生成，禁止客户端伪造收藏事件。
- `GET /meme-media/{id}/{original|thumbnail}` 提供镜像媒体，返回类型准确、按图片可见性校验，绝不接受外部 URL 参数。
- 管理员 API 同步、状态、屏蔽、标签维护由后端任务决定并记录文档；只读无需登录，云收藏需要 JWT。

## Review Focus

1. 部分下载/空或损坏索引不能清空已可用图库；镜像返回有效 MIME 并能下架。
2. 同一图跨分类的去重不丢搜索标签、分类或收藏；跨快照 cursor 不能静默错页。
3. 游客登录合并失败不能丢本机收藏；切换搜索时旧响应不能覆盖新结果。
4. GMT+8 跨日封榜、重启恢复、重复收藏不涨分；低数据量不显示假排名。
5. 动图/大图/权限拒绝/取消分享/网络失败保留当前页面并可重试；客户端不报实际发送成功。
