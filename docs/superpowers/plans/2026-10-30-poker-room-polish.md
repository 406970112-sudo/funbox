# 金花房体验修正

按用户八项明确要求在现有原生小程序房间页内调整，不新增页面或改变服务端记账规则。

1. 复用其他房间邀请卡的布局和二维码居中容器，展示可复制房间码。
2. 座位卡按身份、状态、投入/累计分区，左对齐；多人时保证可读宽度。
3. 喜钱默认无，房主先决定是否登记，有才展开名单，点击单个玩家展开紧凑牌型按钮。勾选改圆形纯色白勾；轮询保留草稿，切场清空。
4. 场间主按钮下增加散场入口，进入账本核对累计后确认散场；成功关闭弹窗，失败保留。
5. 账本累计独立高亮，工具栏箭头独立 flex 居中。
6. 排查和回归等待页同步：缓存有效邀请 token，失败的邀请码停止自动重复生成；后台读取网络失败保留当前画面，用独立同步提示显示，成功清除。

验证：先添加喜钱草稿、散场关闭、邀请失败重试和后台同步回归测试，再实施。运行 node --test miniprogram/tests/*.test.js、JS 语法检查和 git diff --check。原生微信布局如无法运行开发者工具，明确记录真机验证限制。
