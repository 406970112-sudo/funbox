# FunBox 智能商品推荐产品设计方案 V2

> 版本：V2 草案
> 日期：2026-08-01
> 状态：待评审
> 定位：先让你说想买什么，立刻给你结果；筛选只在你觉得不满意时才出现。

## 1. V2 改动背景

V1 把品类、预算、品牌、场景、平台都放在首屏，虽然信息完整，但对"只想说一句想买手机"的用户负担太重。京东购物把筛选放在结果页，用户先看商品，不满意再按条件筛。V2 对齐这个心智：首屏只做一件事，其他条件全部后置成可选筛选。

## 2. 方案补充

1. 首屏只保留"你想买什么"输入框，品类、预算、品牌、场景、平台全部转为结果页筛选条件。
2. 用户直接说一句即可生成推荐，后端负责解析品类、预算和偏好，前端不再要求先选。
3. 结果页提供轻量筛选条：排序 + 筛选按钮 + 已选条件计数。
4. 筛选面板默认收起，展开后可多选条件，应用后只过滤当前结果，不打断浏览。
5. 增加快捷示例词：手机、耳机、平板、3000 左右手机等，点击即填入并可直接生成。
6. 保留追问、详情、对比、历史与反馈闭环，作为结果不满意时的补救路径。

## 3. 产品目标与原则

### 3.1 产品目标

1. 首屏 3 秒内完成"说需求"动作。
2. 默认先出结果，筛选是结果不满意时的补救路径。
3. 筛选即时生效、可收起、可重置，不打断商品浏览。
4. 结果永远先于条件：条件只是对结果的再组织。

### 3.2 设计原则

- 先结果、后条件：不把表单门槛放在用户和商品之间。
- 少选、可补：默认不限，用户需要时才展开。
- 局部生效：筛选只作用于当前结果池，不重新触发 AI。
- 透明可回溯：已选条件始终有计数和重置入口。

## 4. 目标用户与场景

| 用户 | 核心场景 | 产品应满足 |
| --- | --- | --- |
| 只想买手机 | 输入一句，直接看列表 | 一句话出结果，满意就点链接 |
| 有预算但不想填表 | 先看结果再比价 | 用"价格"筛选条件二次缩小 |
| 平台偏好 | 只想在京东买 | 筛选里选"只看京东" |
| 犹豫用户 | 在两三款之间纠结 | 对比、追问、详情继续决策 |

## 5. 页面结构

### 5.1 页面清单

| 页面 | 说明 |
| --- | --- |
| 一句话输入页 | 大输入框 + 快捷示例词 + 生成按钮 |
| 推荐结果页 | 摘要、排序条、筛选条、商品卡列表 |
| 筛选面板 | 底部抽屉/内嵌折叠面板，价格、品牌、场景、平台 |
| 商品详情页 | 参数、理由、平台价格与链接 |
| 对比页 | 2-4 款并排对比 |
| 历史记录 | 最近查询与结果 |

### 5.2 入口

- 工具注册名：`product-recommendation`
- 工具名称：智能商品推荐
- 分类：生活
- 路由：`/tools/product-recommendation`

## 6. 核心流程

```text
输入"想买手机"
  → 后端解析品类/预算/偏好（可都不选）
  → 返回 12 款手机推荐
  → 结果页默认展示商品卡
  → 满意：直接点详情或平台链接
  → 不满意：展开"筛选"
      → 选价格/品牌/场景/平台
      → 列表即时过滤，不重新请求 AI
  → 仍不满意：改输入"再便宜一点"重新生成
```

## 7. 功能设计

### 7.1 一句话输入

- 输入框占位文案："想买什么？直接说，例如：想买个打游戏不卡的手机"
- 快捷示例词：手机、耳机、平板、3000 左右手机、拍照手机，点击即填入。
- 生成按钮固定展示，输入为空时置灰。
- 页面不展示任何必填条件表单。

### 7.2 推荐结果页

- 顶部摘要："为你找到 12 款手机 · 优先续航与游戏"
- 排序：综合推荐 / 价格从低到高 / 价格从高到低 / 匹配度。
- 筛选条：`筛选` 按钮 + 已选条件计数（如 `筛选 2`），未选择时计数隐藏。
- 商品卡沿用 V1：名称、理由、参考价、平台链接、适合人群、反馈。

### 7.3 筛选面板

- 点击筛选条展开面板，包含：
  - 价格：1000 以内 / 1000-2000 / 2000-3000 / 3000-5000 / 5000+
  - 品牌：小米 / 华为 / 苹果 / OPPO / vivo / 荣耀 / 一加 / 不限
  - 场景：游戏 / 拍照 / 续航 / 办公 / 轻便 / 画质
  - 平台：京东 / 淘宝 / 拼多多
- 所有选项非必选，默认不限。
- 点"查看 N 款"应用筛选；点"重置"恢复默认。
- 筛选基于当前返回的商品池在本地执行，不重新调 DeepSeek。
- 平台筛选时，缺少对应链接的商品自动隐藏。

### 7.4 追问与调整

- 结果页保留快捷操作："再便宜一点"、"更看重拍照"、"优先续航"、"只看京东"。
- 点击后作为新的输入条件重新生成，而非筛选当前列表。

### 7.5 详情、对比、历史与反馈

沿用 V1：

- 详情页：完整参数、为什么值得买、各平台价格与链接。
- 对比页：2-4 款商品并排对比。
- 历史：登录用户最近 20 条查询。
- 反馈：商品卡上的有帮助/没帮助。

## 8. AI 与数据架构

### 8.1 DeepSeek 复用方式

- 继续复用翻译的 `DEEPSEEK_API_KEY` 与 `config.DeepSeekConfig`。
- DeepSeek 只负责：自然语言解析、推荐排序理由、摘要文案。
- 筛选和排序在结果页本地执行，不消耗 AI 额度。

### 8.2 请求与响应

`POST /api/v1/product-recommendation/query` 允许只传 `query`，其余字段可选。

```json
{
  "query": "想买手机，3000 左右",
  "category": "",
  "budgetMin": null,
  "budgetMax": null,
  "brands": [],
  "scenarios": [],
  "platforms": []
}
```

响应在 V1 基础上新增 `availableFilters`：

```json
{
  "queryId": "rec_20260801_0001",
  "category": "phone",
  "summary": "为你找到 12 款手机，优先续航与游戏",
  "items": [],
  "availableFilters": {
    "budgetRanges": [
      { "min": 1000, "max": 2000, "label": "1000-2000" },
      { "min": 2000, "max": 3000, "label": "2000-3000" }
    ],
    "brands": ["Redmi", "一加", "荣耀"],
    "scenarios": ["游戏", "续航", "影像"],
    "platforms": ["jd", "taobao", "pdd"]
  },
  "ai": "deepseek",
  "disclaimer": "参考价来自商品库快照，实际价格与库存以平台页面为准。"
}
```

### 8.3 商品数据源

沿用 V1：维护式商品库先行，M3 接入京东联盟、淘宝联盟、多多进宝。

## 9. 接口设计

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/v1/product-recommendation/query` | 只传 query 也可生成，返回 `availableFilters` |
| GET | `/api/v1/product-recommendation/catalog` | 商品库 |
| GET | `/api/v1/product-recommendation/queries/{queryID}` | 单次结果 |
| POST | `/api/v1/product-recommendation/feedback` | 反馈 |
| GET | `/api/v1/product-recommendation/history` | 历史 |

## 10. 页面与交互设计

- 首屏输入区居中放大，背景保持浅蓝，减少视觉噪音。
- 筛选条贴近京东心智：左侧排序，右侧筛选按钮与计数。
- 筛选面板使用底部抽屉，圆角不超过 16px，选项用 chips。
- 筛选应用后列表即时更新，面板自动收起或保留由用户决定。
- 支持浅色与深色主题；320px、390px、430px 下无文字溢出与元素重叠。

## 11. 状态与异常处理

| 场景 | 处理 |
| --- | --- |
| 只说"想买东西" | 返回热门推荐，并提示"告诉我具体品类会更准" |
| DeepSeek 超时 | 降级为规则推荐，返回 `ai: "fallback"` |
| 筛选后无结果 | 显示空态 + "重置筛选" |
| 平台链接缺失 | 平台筛选中隐藏该商品 |
| 价格快照过期 | 标 `stale`，文案提示价格可能已变化 |

## 12. 分期实施

### M1 一句话输入 + 基础筛选

- 一句话输入页、快捷示例词
- 结果页、排序、价格/平台筛选
- 平台链接跳转、反馈

### M2 完整筛选与追问

- 品牌/场景筛选面板、筛选计数与重置
- 追问、对比、历史记录

### M3 联盟 API 与实时比价

- 京东联盟、淘宝联盟、多多进宝接入
- 实时价格与降价提醒

## 13. 成功指标

1. 从输入到看到结果，p90 不超过 3 秒。
2. 用户首次使用无需展开筛选即可完成购买意图的比例不低于 60%。
3. 筛选功能使用率不低于结果页访问量的 30%。
4. 推荐"有帮助"反馈率不低于 70%。
5. 平台链接可点击率 100%。

## 14. 明确不做

- 不在首屏强制用户选择任何条件。
- 不做多步向导式选品。
- 不做无法回溯、无法重置的筛选。
- 不承诺"全网最低价"或"绝对最优选择"。

## 15. 验收清单

- [ ] 只输入一句话可以生成推荐列表。
- [ ] 首屏没有必填条件。
- [ ] 结果页有排序条和筛选按钮。
- [ ] 筛选面板可展开、应用、重置、收起。
- [ ] 筛选只作用于当前结果，不重新请求 AI。
- [ ] 平台筛选会隐藏缺少对应链接的商品。

- [ ] 320px、390px、430px 视口无文字溢出与元素重叠。
