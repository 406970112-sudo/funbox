# 通用记分设计 V2

2026-10-30。按用户三项反馈修订的静态方案，尚未修改业务代码。

## 本轮修订要求

1. 首页仅在原有麻将记分、炸金花后追加「通用记分」卡片。保留原品牌、文案、组合插画、分类标题及既有入口，不采用 V1 的首页改版。
2. 创建房间沿用当前麻将建房页面结构：顶部品牌与插画、创建／加入切换、房间名原位编辑、昵称输入框、密码原位编辑、提示及创建按钮。顶部使用新通用记分插画；必要文案去除麻将和固定四人表述。图中「灵活人数」不代表新增人数配置控件。
3. 结算沿用麻将房流程：房主打开确认弹层，确认或修改每分金额，核对每名成员当前分数和预计金额，点击「确认并结算」。修改金额同步更新预览；结算后不可修改。其他成员不能提交结算。

## 图示

- `01-home-and-create.png`：保留首页、追加入口；通用记分创建页面。
- `02-host-settlement.png`：房主结算确认弹层及结算结果。6 人积分合计为 0，示例由房主将每分金额设为 0.50 元，结果和转账建议均使用这一金额。

仍保留此前明确的人数不限制为四人的方向；成员列表、批量给分和实时同步以麻将流程为基础扩展。中途加入／退出及实际容量不在本轮新增定义。

本轮采用内置 `image_gen.imagegen`，以原有麻将 V3 图和项目正式插画图集为参考。完整提示词见 `image-prompts.json`。图片是概念方案，页面像素细节以现有小程序源码为准，未被要求改变的首页区域实施时必须保留；不能按生成图重做原首页。图中金额、昵称为样例。V1 予以保留供追溯，V2 为本轮评审版本。
