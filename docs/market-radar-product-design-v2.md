# FunBox 市场雷达 2.0 产品设计方案

## 1. 文档信息

- 文档状态：待评审
- 日期：2026-08-01
- 范围：市场雷达板块覆盖、信息架构、功能补齐、数据规则与分期实施
- 原则：只补齐可验证的行情与资讯能力，不引入投资建议或无法追溯的因果解读

## 2. 现状与问题

当前市场雷达已完成 V1 闭环：从东方财富拉取板块行情，后端计算涨跌幅、趋势、强弱脉搏和异动，前端提供分类切换、周期切换、板块排行、板块详情和关注。

主要问题：

| 现状 | 问题 |
| --- | --- |
| 只有 AI 5 个板块 + 有色 5 个板块 | 覆盖太窄，用户找不到大部分关心的行业 |
| “全球”是 AI 与有色的并集 | 名称有误导，用户会以为能看到全球市场 |
| 页面只渲染排行前 5 名 | 看不到完整排名，信息被截断 |
| 只有涨跌幅一种排序 | 无法按成交额、换手率、涨跌家数判断板块热度 |
| 只有 1/5/20 日三个周期 | 缺少中长期趋势观察维度 |
| 异动信号只有一条、定义单一 | 无法覆盖放量、反转、扩散等常见异动 |
| 详情只有 3 只代表标的 | 看不到完整成分股和板块资讯 |
| 关注只存在页面内存 | 退出或刷新后丢失，无法形成自选池 |
| 没有搜索和指数总览 | 用户难以快速定位板块，也缺少市场全局参照 |

## 3. 产品目标

1. 板块池从 10 个扩充到 40 个以上，覆盖 AI 科技、新能源、医药消费、金融地产、周期制造和热门题材。
2. 从“看涨幅榜”升级为“可搜索、可排序、可筛选、可追踪的板块雷达”。
3. 从“单板块详情页”升级为包含指标、成分股、资讯和关联板块的情报中心。
4. 增加全球指数带和更丰富的异动信号，让用户先看全局、再找主线、最后看细节。
5. 关注列表本地持久化，后续可平滑升级为账号同步。
6. 所有数字保留来源、更新时间和计算口径，不展示无法验证的“上涨原因”。

## 4. 板块覆盖扩充

### 4.1 分类结构

将现有“全球 / AI / 有色”改为更准确的分类体系：

| 分类 | 首批板块数 | 说明 |
| --- | --- | --- |
| 全市场 | 46 | 全部行业与概念板块的并集，替代原“全球” |
| AI 科技 | 10 | AI 算力、CPO、AI 芯片、人工智能、云计算、大数据、信创、半导体、机器人、智能驾驶 |
| 新能源 | 6 | 光伏、锂电池、储能、风电、充电桩、固态电池 |
| 医药消费 | 6 | 创新药、医疗器械、生物医药、白酒、食品饮料、医疗服务 |
| 金融地产 | 6 | 证券、银行、保险、房地产、多元金融、互联网金融 |
| 周期制造 | 8 | 有色金属、贵金属、钢铁、煤炭、石油、化工、军工、工程机械 |
| 热门题材 | 10 | 低空经济、卫星互联网、量子科技、数据要素、华为概念、液冷服务器、PCB、核电、算力租赁、合成生物 |

首批共 46 个板块，后端保留配置化扩展能力，后续可继续增加行业和概念板块，不要求前端改代码。

### 4.2 指数带

新增独立“指数带”，与板块池分开展示：

- A 股：上证指数、深证成指、创业板指、科创 50、沪深 300、中证 500
- 港股：恒生指数、恒生科技
- 海外：纳斯达克、标普 500、道琼斯、日经 225

指数展示点位、涨跌幅、更新时间；指数带只做行情参照，不进入板块强弱排序。

### 4.3 覆盖策略

- 板块 ID 和分类关系全部由后端配置管理，前端只消费接口返回的分类与板块。
- 单个板块拉取失败时继续保留其他板块，接口通过 `coverage` 汇报缺失。
- 分类内必须有至少 3 个有效板块，否则接口降级为 `stale` 或明确错误。
- 首批新增以“行业板块 + 高热度概念板块”为主，避免冷门且流动性不足的板块。

## 5. 信息架构

页面顶部改为四个一级视图，保持移动端单列滚动：

1. 总览：大盘脉搏、指数带、涨跌分布、板块速览
2. 板块：分类、周期、排序、搜索、完整板块排行
3. 异动：领涨、领跌、放量、反转、扩散五类信号
4. 关注：持久化自选板块，带实时涨跌状态

板块详情保留为总览或板块列表的下一级页面。

## 6. 功能清单

### 6.1 市场总览

- 大盘脉搏：按当前分类统计上涨/下跌板块占比，保留 0-100 分和强弱标签。
- 指数带：横向滑动展示 12 个指数，点击可查看指数详情。
- 涨跌分布：按涨幅区间统计板块数量，形成直观的强弱分布。
- 成交额概览：展示当前分类总成交额和换手率中位数。
- 板块速览：展示全市场最强 3 个、最弱 3 个板块，点击进入详情。

### 6.2 板块列表

- 分类切换：全市场、AI 科技、新能源、医药消费、金融地产、周期制造、热门题材。
- 周期切换：1 日、5 日、20 日，后续可扩展 60 日。
- 排序切换：涨跌幅、成交额、换手率、上涨家数占比、相对强弱。
- 搜索：按板块名称或代码模糊搜索。
- 完整排行：不再截断前 5 名，默认一屏展示 8-10 行，继续滚动查看全部。
- 行内信息：板块名、迷你走势、涨跌幅、成交额、换手率。

### 6.3 异动信号

异动视图按信号类型分组，全部由后端基于快照数据确定性计算：

| 信号 | 规则 |
| --- | --- |
| 领涨 | 当前周期涨幅前 5 |
| 领跌 | 当前周期跌幅前 5 |
| 放量 | 当日量比不低于 1.5，K 线可用时以近 20 日均值为准 |
| 反转 | 5 日与 20 日涨跌方向相反，且两个周期幅度均超过 3% |
| 扩散 | 上涨家数占比不低于 70%，且板块当日上涨 |

每条信号显示板块名、触发原因和可跳转详情的入口。

### 6.4 板块详情

- 多周期表现：1/5/20 日涨跌幅并列展示，趋势图支持切换周期。
- 行情指标：最新点位、成交额、换手率、上涨/下跌家数、成分覆盖。
- 强度参照：板块相对全市场分类的排名，以及相对 20 日均值的位置。
- 成分股：默认展示按流通市值选出的 3 只代表标的，支持“查看全部”。
- 完整成分：按市值、涨跌幅或成交额排序，分页加载。
- 板块资讯：展示与该板块相关的真实新闻，来源和原文链接可见。
- 关联板块：同分类中走势相关性最高的 3 个板块。
- 关注操作：详情页与列表行均可加入或移除关注。
- 计算口径：展示数据来源、更新时间、延迟状态和计算方法。

### 6.5 我的关注

- 关注列表持久化到本地：Web 使用 `localStorage`，原生使用 `SecureStore`。
- 关注列表展示当前涨跌幅、迷你走势和更新时间。
- 支持按涨跌幅排序、移除关注、清空关注。
- 刷新时保留旧数据并标记 stale，失败时提供重试。
- V2 不提供账号同步；结构上预留后续服务端接口。

## 7. 页面与交互设计

- 继续使用 FunBox 现有视觉体系：浅蓝背景、白色表面、深色 `#151b3b` 重点区、主色 `#4b6bff`。
- 内容容器保持最大 430px 移动宽度，宽屏居中。
- 使用开放列表和细分隔线，不新增嵌套卡片。
- 圆角不超过 8px，图标沿用 Material Community Icons。
- 排序、周期、分类使用分段控件；搜索使用输入框；关注使用图标按钮。
- 支持浅色与深色主题，文本在 320px、390px、430px 视口内不溢出。
- 所有数字变化保持固定宽度，避免刷新时布局跳动。

## 8. 数据与计算规则

### 8.1 快照扩展

现有 `GET /api/v1/market-radar/snapshot` 扩展为：

```json
{
  "categories": [],
  "periods": [],
  "indices": [],
  "sectors": [],
  "signals": [],
  "pulses": {},
  "coverage": {},
  "fetchedAt": "",
  "source": "eastmoney",
  "sourceUrl": "",
  "stale": false
}
```

- `sectors` 只返回列表页需要的摘要数据。
- 完整成分股改为 `GET /api/v1/market-radar/sectors/{id}` 按需拉取。
- `indices` 和 `signals` 由后端基于同一份快照计算。

### 8.2 计算口径

- 1/5/20 日周期收益直接使用东方财富板块列表的 `f3`、`f109`、`f110` 字段，快照不再依赖逐板块 K 线。
- 成交额、换手率、涨跌家数、成分覆盖沿用现有字段，不改变单位。
- 放量信号默认使用板块量比 `f10`；K 线增强数据可用时回退到近 20 日均值基准。
- 反转信号要求两个周期均达到阈值，避免噪声触发。
- 上涨家数占比 = 上涨板块数 / (上涨板块数 + 下跌板块数)，不把平盘计入。
- 所有信号排序稳定，平局按板块 ID 排序。

### 8.3 资讯策略

- 板块资讯只使用真实来源：优先复用热点速览现有 RSS 聚合能力，后续可接入东方财富板块资讯。
- 资讯展示标题、短摘要、来源和原文链接，不在 FunBox 内完整转载正文。
- 不生成“上涨原因”；如后续提供 AI 简报，只能把真实指标与真实资讯组合成陈述句，并标注来源。

### 8.4 关注存储

- 关注板块 ID 列表本地持久化，不随快照刷新丢失。
- 存储格式保持简单数组，兼容未来账号同步。
- 本地数据损坏时自动回退为空关注列表，不阻塞页面加载。

## 9. 接口与数据流

1. 前端进入市场雷达，请求快照接口。
2. 后端通过行业/概念两个板块列表接口分页拉取 46 个板块摘要，再拉取 12 个指数行情，计算排行、脉搏和信号。
3. 快照在 TTL 内直接返回缓存；刷新失败时返回最近一次成功快照并标记 `stale`。
4. K 线走势在后台异步增强快照，上游不可用时快照仍正常返回，走势图暂为空。
5. 前端校验响应后渲染，列表页不阻塞于成分股详情。
6. 用户进入详情时，按需请求板块完整成分股和关联资讯。
7. 关注列表仅写本地存储，不上传账号。

## 10. 实施分期

### P1 扩板块与完整排行

- 板块池扩展到 46 个，分类重构为 7 类。
- 列表不再截断，支持排序切换和搜索。
- 分类与周期切换、完整排行、排序筛选全部可用。

### P2 详情增强与关注持久化

- 板块详情增加完整成分股、多周期对比、关联板块。
- 关注列表本地持久化，新增“关注”一级视图。
- 刷新、空状态、异常状态完整覆盖。

### P3 指数带与异动中心

- 新增 12 个指数和指数详情。
- 新增放量、反转、扩散等异动信号。
- 板块详情接入真实资讯。

### V3 后续可选

- AI 每日盘面简报：仅基于真实指标和资讯生成。
- 关注阈值提醒：自选板块达到涨跌幅或放量阈值时提醒。
- 账号级关注同步。
- 板块对比、历史回看和导出。

## 11. 成功标准

1. 板块数量从 10 个提升到 46 个，分类覆盖 7 类，板块列表可看到全部排名。
2. 分类、周期、排序、搜索四项操作均能稳定改变列表结果。
3. 关注在刷新、退出和重新进入后仍然存在。
4. 异动视图至少包含领涨、领跌、放量、反转、扩散五类信号。
5. 详情页能查看全部成分股、真实资讯和计算口径。
6. 指数带、快照、详情、关注、异动五个页面在桌面与移动视口无重叠、无空白、无控制台错误。
7. 浅色与深色主题均可用，320-430px 视口不溢出。
8. 所有行情数字保留来源、更新时间和 stale 标记，不展示演示数据。

## 12. 明确不做

- 不提供实时行情保证，继续使用东方财富公开延迟数据。
- 不提供买卖建议、自动交易或收益预测。
- 不生成无法追溯的“上涨原因”。
- 不在 V2 引入账号级关注同步、推送提醒和付费数据源。
- 不重做 FunBox 主题、底部导航和工具注册体系。
