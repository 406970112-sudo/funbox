# 通用记分设计 V1

2026-10-30，初版静态方案，待用户评审。未修改小程序业务代码。

## 设计依据

参考当前小程序首页、麻将创建页、房间页，以及 `docs/mahjong-experience-v3`。沿用浅灰蓝背景、白色圆角卡片、蓝色主按钮及轻量立体插画。

首页保留麻将记分与炸金花，新增独立「通用记分」入口，分类标题调整为「选择记分方式」。通用房间剥离麻将插画、东南西北座位和牌桌术语，使用昵称头像、房间成员、积分榜、记分记录等中性表达。

## 初版提案

- 沿用创建／加入、扫码及邀请、昵称和密码、实时同步、批量给分、结束结算的主要流程。
- 人数方案由设计者暂定为 2 人起、不设固定名额，无需在创建时选择人数；最终技术容量需实施时明确。这不是已经实现的无限人数能力。
- 用 6 人示例验证布局。成员使用纵向列表，更多成员滚动展示，不固定四个空位。示例不代表人数上限。
- 保留原来的零和给分逻辑：我向其他成员给分，可一次给多人，自己扣分、对方加分；没有新增独立加减分模式。
- 为适应更多成员，提出将给分表单收进底部弹层；实际实现应允许列表滚动，并保持汇总和确认按钮可操作。
- 保留结束时设置每分金额和转账建议。图二展示未提交给分的独立弹层状态，右侧结算以原始积分为样例，并非该笔给分提交后的结果。
- 创建后等待阶段人数动态展示，最低 2 人即可开始。本轮不定义中途加入／退出等新增业务规则。
