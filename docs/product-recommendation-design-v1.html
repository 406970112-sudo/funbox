PRODUCT DESIGN

一次回答：
买什么、为什么、去哪买

用户用一句话描述购买需求，系统解析品类、预算和偏好，给出带理由、参考价和电商链接的推荐列表。

要解决的问题

搜索结果同质化，缺少按预算与场景的差异化

参数看不懂，推荐理由与用户需求不挂钩

京东、淘宝、拼多多要分别打开才能比价

没有追问、对比与反馈，决策闭环缺失

核心链路

一句话输入购买需求
结构化解析品类 / 预算 / 偏好
商品库召回候选
DeepSeek 生成理由与文案
返回推荐列表与平台链接

功能范围

需求输入与自然语言解析
推荐列表 + 可解释理由
多平台参考价与购买链接
2-4 款商品对比
追问调整与历史记录

成功指标

< 10s推荐生成 p90 耗时
≥ 70%推荐有帮助反馈率
100%链接可点击跳转
≥ 25%电商平台跳转率

关键决策

复用翻译的 DeepSeek Key

后端继续使用 DEEPSEEK_API_KEY 与 config.DeepSeekConfig，不新增前端 Key。

先事实、后观点

V1 使用维护式商品库与链接，理由只引用结构化参数；M3 再接入京东联盟、淘宝联盟、多多进宝。
