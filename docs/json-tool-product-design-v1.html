一句话定位

本地优先的 JSON 转换与语义对比工作台

粘贴真实 JSON 即可格式化、清洗、转换格式、生成类型与 Schema，并把任意两份真实 JSON 做语义级对比。

要解决的问题

  • 在线工具需要上传内部与生产数据，存在泄露风险
  • 格式化、转换、对比分散在不同站点，来回搬运
  • 文本 diff 把键顺序变化当成差异，真实变更被淹没
  • 没有历史、模板与批量能力，重复劳动

关键决策

推荐 A · 本地处理 解析、转换、对比全部在浏览器 Worker 完成，数据零上传
B · 云端转换 能力一致但需要上传数据，V1 不做
C · 纯查看器 只格式化不转换，能力不足

一期范围（全量交付）

  • ✓转换器：格式化、清洗、JSON→YAML/CSV/XML/TS/Schema/SQL
  • ✓对比器：语义树对比、忽略配置、变更清单与合并
  • ✓历史记录、模板与收藏
  • ✓敏感字段遮蔽与本地隐私

成功指标

20s进入工具到完成一次转换
0核心链路数据上传请求
100%示例为真实数据并标注来源
0键顺序导致的伪差异
