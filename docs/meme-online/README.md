## 功能

在表情包页通过“图库 / 联网搜图”切换。联网模式明确提交关键词、选择来源、查看每源状态、失败重试、上一页/下一页；结果复用详情、来源复制、收藏、预览、分享与相册保存。首页仍没有藏图快捷入口。在线结果在独立持久表中登记，不污染原分类图库或被图库同步删除。

适配参考 [o98k-ok/meme](https://github.com/o98k-ok/meme)，代码来源说明见 backend/NOTICE-meme-online.md。沿用其来源和数据映射，在现有 Go 服务内实现，无需额外运行 MCP 进程。

本次真实来源验证：斗图啦、胖哒搜索/翻页可用，原图实际读取 JPEG/GIF 成功；搜狗返回限制响应，界面显示来源错误；趣斗图/斗图 API 的现有接口不可用，暂禁用；抖音未配置 Cookie 时禁用。来源可用性受网站变化影响，不承诺六源全部可用，也不把网络搜索结果当热度排行。

## 配置与接口

服务端环境变量（不得写入小程序或提交 Cookie）：

```dotenv
MEME_ONLINE_ENABLED=true
MEME_ONLINE_SOURCES=doutula,pdan,sougou,douyin
MEME_DOUYIN_COOKIE=
```

- `GET /api/v1/memes/online/sources`：来源名称、启用状态、禁用原因与项目归属。
- `GET /api/v1/memes/online/search?q=猫&sources=doutula,pdan&page=1&limit=36`：来源状态、稳定图片 ID、聚合分页、缓存标识。
- 在线 ID 为 `online-<64hex>`，沿用 `/memes/{id}`、收藏、事件与 `/meme-media/` 接口。小程序 HTTPS 网关严格兼容此格式。

接口限流、并发/超时与响应大小限制；来源请求地址固定，媒体 URL 只能从登记 ID 查找；TLS 证书正常验证，拨号锁定已验证的公共 IP，阻止 IPv4/IPv6 内网、DNS 变换及不安全重定向。抖音 Cookie 只发送到指定主机，不返回客户端、不写响应日志。来源故障分开显示，不能伪装成“无结果”。

聚合分页采用有界短期会话保存每源队列和上游页码，避免全局截断后漏掉结果；失败/取消构页会恢复队列、游标和去重状态。会话容量 16、TTL 3 分钟、最多 50 页；过期后重新搜索的结果可能因来源更新而变化。
