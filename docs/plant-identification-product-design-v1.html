05 识别历史 · 记录 + 删除 + 空态

DESIGN NOTES

一期完整的信息闭环

识别不止回答“是什么”：从候选结果到详情页，六层信息全部来自真实数据源，缺失字段不补造。

核心链路

拍摄/选图 → PlantNet 识别候选物种 + score 聚合资料 → GBIF 分类 + Wikipedia 描述 + iNaturalist 图片 结果呈现 → 主结果 + 候选 + 食用提示 + 来源 闭环沉淀 → 历史、收藏、纠错反馈

食用提示规则

  • 词条有可引用原文时，展示原文片段并标注来源与快照时间。
  • 无可靠资料时，固定显示“暂无可信食用资料，请勿采食”。
  • 人工审校警示表只做高风险提示，不做“可食”判断。
字段级 source / fetchedAt

边界与异常

场景 处理
置信度 < 60% 提示重拍，候选列表继续可查
词条缺失 显示“暂无”，不补造内容
识别服务失败 明确提示 + 重试，不出占位物种
图片 404 占位“图片整理中”，文字资料照常

视觉与一期范围

  • 沿用 FunBox 浅蓝画布、深色文字、品牌蓝；植物功能补充绿色与嫩绿。
  • 320 / 390 / 430px 下文字不溢出、元素不重叠，深浅主题均可用。
  • 所有页面与接口在同一个版本交付，不分期。
