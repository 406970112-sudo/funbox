FunBox 功能建议与问题反馈一体化 · 管理端设计

反馈管理统一承载问题与建议，列表可筛可搜，详情可处理并回写真实结果。

2026-08-04 一期交付 真实数据

现状

  • 管理后台只能查看反馈，不能筛选、处理或回复。
  • 问题反馈与功能建议没有统一工作台。
  • 处理结果无法回到用户消息中心。

方案

  • 后台首页入口改为“反馈管理”。
  • 类型、状态、关键词筛选均由服务端真实统计。
  • 详情支持开始处理、提交结果、修改结果。
  • 提交结果后推送 feedback.resolved 并生成未读通知。

真实数据红线

  • 筛选项数量来自数据库，不写死。
  • 处理人、处理时间、回复来自真实管理员操作。
  • 用户已读时间由用户打开详情触发。
  • 设计图为真实上传文件，私有鉴权读取。

设计要点

1

桌面双栏：左侧列表，右侧详情，沿用现有后台布局。

2

类型与状态徽标帮助快速识别。

3

处理结果必填 10-1000 字，提交后状态与通知一起更新。

4

移动端复用同一列表/详情组件，仅改排列方式。

设计稿中的用户、时间和回复内容仅作版式示意；交付后页面只展示真实数据库与真实 API 返回的数据。
