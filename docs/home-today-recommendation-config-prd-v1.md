# FunBox 首页今日推荐配置化 产品设计方案 V1

> 版本：V1
> 日期：2026-08-02
> 状态：待评审
> 适用端：Expo 移动端首页 / 管理后台 Web / Go 后端
> 定位：把首页「今日推荐」从单一固定 banner，升级为管理员可配置、内容全部来自真实功能注册表、一期交付完整闭环的推荐模块。

## 1. 背景与问题

当前首页内容顺序为：

`品牌区 → 搜索 → 今日推荐 → 最近使用 → 全部工具 → 放松一下（游戏）→ 会员权益模块 → 底部导航`

「今日推荐」现状：

1. 页面固定渲染一张卡片，逻辑为 `DEFAULT_RECOMMENDATION_TOOL_ID = 'card-score'`，找不到时回退到工具列表第一项。管理员无法控制展示哪一项。
2. 展示内容直接读取真实工具注册表（`backend/internal/access/feature_registry.json`），但没有配置能力：无法排期、无法换序、无法隐藏、无法多卡展示。
3. 没有真实效果数据。运营无法得知推荐位带来了多少曝光、点击和转化。
4. 缺少管理后台入口。功能注册、角色权限、会员运营均已有后台页面，唯独首页推荐没有运营配置页。
5. 仓库中存在一个 `FeaturedToolCarousel` 组件（标题「精选功能」），但首页当前并未渲染它，因此线上首页没有「精选功能」板块；该组件的卡片视觉与轮播交互可复用为「今日推荐」多卡轮播的设计语言。

产品判断：

- 首页第一屏推荐位是运营资源位，配置能力是一期必须项，不能用代码改默认值代替。
- 推荐内容必须全部来自真实功能注册表，禁止 mock、禁止手写推荐词、禁止展示未注册或用户无权限的功能。
- 排期、校验、审计、效果数据属于同一闭环，全部一期完成，不做分期。

## 2. 设计目标与原则

### 2.1 核心目标

1. 管理员在后台配置「今日推荐」的展示内容、顺序、时间范围与文案覆盖。
2. 首页只展示真实存在的工具与游戏，按当前用户角色和功能可见性过滤。
3. 每次配置变更都有审计记录，推荐位有真实曝光与点击统计。
4. 推荐位最少保留 1 个；无任何配置时默认推荐「打牌记分」（`card-score`）。
5. 多张推荐卡横向轮播，不向下撑开页面；视觉与交互沿用现有「精选功能」轮播。
6. 无配置、配置失效、接口失败都有真实兜底，不渲染假数据。

### 2.2 设计原则

1. **真实数据唯一事实源**：功能目录以 `feature_registry.json` 为唯一事实源；推荐配置只存引用（feature ID），不复制名称、图标、简介、路由、颜色。
2. **所见即所得**：后台预览与首页实际渲染使用同一套合并逻辑，校验规则一致。
3. **运营可解释**：首页推荐卡标注来源（工具/游戏）与真实状态，点击后进入真实路由。
4. **权限一致**：推荐候选必须通过现有角色可见性、状态、隐藏规则过滤，不允许出现“看得见进不去”的入口。
5. **一期闭环**：配置、排期、发布、效果、审计一次交付，不设二期。

## 3. 信息架构

### 3.1 首页结构（移动端）

首页只改动「今日推荐」模块，其余内容与顺序保持现状：

`品牌区 → 搜索 → 今日推荐（新模块）→ 最近使用 → 全部工具 → 放松一下 → 会员权益模块 → 底部导航`

说明：

- 品牌区、搜索、「最近使用」、「全部工具」、「放松一下」（游戏）、会员权益模块、底部导航均不改动。
- 首页当前没有「精选功能」板块，方案不新增该板块；`FeaturedToolCarousel` 组件保留不动，只复用其卡片风格与交互逻辑（见 4.5）。
- 「今日推荐」多卡展示时采用横向轮播，卡片样式沿用现有 `FeaturedToolCarousel` 的视觉语言（见 4.5）。

### 3.2 管理后台结构

在现有 `AdminShell` 侧栏「内容运营」分组下新增页面：

`/admin/recommendations` 首页推荐管理

页面内三个视图：

| 视图 | 内容 |
| --- | --- |
| 推荐位配置 | 槽位列表、启用状态、顺序、今日生效项 |
| 槽位编辑 | 功能选择、文案覆盖、排期、角色与可见性校验结果、实时预览 |
| 效果概览 | 最近 30 天曝光、点击、点击率、Top 推荐位 |

## 4. 功能设计

### 4.1 首页今日推荐模块

#### 展示规则

- 首页从 `GET /api/v1/home/recommendations` 获取当天生效的推荐位。
- 推荐位最少 1 个、最多 3 个。配置为 0 个时，接口返回 `source: "fallback"` 与默认推荐「打牌记分」（`card-score`）。
- 同日最多展示 3 张卡片；轮播计数与分页圆点只统计当天实际展示的卡片数（例如 `01 / 03`），不包含未来排期项。
- 多张推荐卡使用横向轮播：卡片横向排列、右侧露出下一张卡片边缘，支持手势滑动、自动轮播（遵循系统“减少动态效果”）、点按页码小圆点与 `01 / N` 计数，布局与交互完全沿用现有「精选功能」轮播。
- 卡片来源必须为真实功能注册表中的 `available` 工具或 `playable` 游戏。
- 卡片内容：
  - 类型角标：`工具` / `游戏`
  - 图标：注册表 `icon`
  - 名称：优先槽位 `titleOverride`，未配置时使用注册表 `name`
  - 简介：优先槽位 `descriptionOverride`，未配置时使用注册表 `tagline`
  - CTA：优先槽位 `ctaLabelOverride`，未配置时工具使用 `usageLabel`、游戏使用 `开始游戏`
  - 主色：注册表 `accentColor`
  - 路由：注册表 `route`
- 点击卡片记录 `click` 事件后跳转真实路由。
- 仅有 1 个生效推荐位时，展示单张卡片，不渲染分页圆点。

#### 兜底规则

| 场景 | 表现 |
| --- | --- |
| 当天没有启用中的槽位（配置为 0） | 返回 `fallback` 推荐：默认「打牌记分」（`card-score`）；若该功能不可用，再回退到当前用户最近使用过的可见工具，没有则取工具列表第一项，并在接口字段中标注 `source: "fallback"` |
| 配置槽位被隐藏/下架/角色不可见 | 服务端按当前用户过滤后从返回中剔除，不渲染不可达入口 |
| 接口失败 | 首页不渲染推荐区，保留空位，不显示本地 mock |
| 启用槽位不足 1 个 | 管理后台阻止保存，并提示「至少保留 1 个推荐位」 |

### 4.2 管理后台配置

#### 推荐位列表

- 展示全部槽位：序号、功能名称与类型、生效时间、启用状态、操作。
- 支持上移/下移调整当天优先级。
- 支持复制槽位、删除槽位。
- 删除最后一个启用槽位时阻止操作，并提示「至少保留 1 个推荐位」。
- 关闭最后一个启用槽位时阻止操作，给出相同提示。
- 顶部状态条展示真实统计：`今日生效 N 个`、`默认推荐 打牌记分`、`未启用 M 个`。

#### 槽位编辑

字段说明：

| 字段 | 说明 | 校验 |
| --- | --- | --- |
| 推荐功能 | 从真实注册表选择工具或游戏 | 必须存在；状态必须 `available` / `playable`；不得 `hiddenFromList: true`；当前角色可见 |
| 展示类型 | 工具 / 游戏 | 自动按注册表 route 前缀判断，不可手填 |
| 标题覆盖 | 可选，覆盖卡片标题 | 2-24 字；为空时使用真实名称 |
| 简介覆盖 | 可选，覆盖卡片简介 | 2-60 字；为空时使用真实 tagline |
| CTA 覆盖 | 可选，覆盖按钮文案 | 2-12 字；为空时使用真实文案 |
| 生效范围 | 全部日期 / 指定日期区间 / 每周 N 天 | 开始不得晚于结束 |
| 启用状态 | 开关 | 关闭后立即从首页消失 |

保存规则：

- 任一字段非法即阻止保存，并在对应字段给出真实原因。
- 保存后必须仍满足“至少 1 个启用中推荐位”，否则保存失败。
- 保存成功后写入审计记录：管理员、动作、槽位、变更字段、时间。
- 同一天启用多个槽位时按列表顺序展示，最多 3 个。

#### 实时预览

- 编辑区右侧（桌面端）或下方（移动端）展示与首页完全一致的卡片渲染。
- 预览卡片数据由前端用「选择的功能 + 覆盖文案」按首页合并逻辑渲染，并标出当前可见性校验结果。
- 预览不单独造数据，只使用已选功能的真实字段。

### 4.3 排期与发布

- 槽位支持 `startsOn` / `endsOn`（含当天）与 `weekdays`（1-7）。
- 服务端按服务器日期（Asia/Shanghai）计算当天生效槽位，不依赖客户端时间。
- 首页接口可传 `date` 参数用于运营预览某一天；管理后台日历视图按真实配置展示每天生效槽位。
- 发布动作即保存：无草稿/审核双状态，避免“配置了但没发布”的隐性分期。

### 4.4 效果统计

数据来自真实埋点事件表：

| 指标 | 口径 |
| --- | --- |
| 曝光 | 首页推荐模块渲染并可见时上报一次，按用户按日去重 |
| 点击 | 点击推荐卡上报一次 |
| 点击率 | 点击 / 曝光 |
| Top 推荐位 | 按点击率排序的前 5 个槽位 |

- 管理后台效果概览按槽位展示最近 30 天数据。
- 新配置无数据时不显示 0 造数，显示「暂无曝光」空态。

### 4.5 轮播交互（沿用现有 `FeaturedToolCarousel` 组件规范）

- 卡片高度 172px、圆角 21px、内边距 18px，右侧露边 16px，卡片间距 10px。
- 自动播放间隔 5.2 秒，到达首尾后折返；系统开启“减少动态效果”时不自动轮播。
- 页码区显示 `01 / N` 计数与可点按小圆点，当前页圆点拉长。
- 卡片主色、图标、名称、简介、CTA 全部来自真实功能字段或已保存的覆盖文案。

## 5. 真实数据契约

### 5.1 数据来源

| 数据 | 来源 |
| --- | --- |
| 工具/游戏目录 | `backend/internal/access/feature_registry.json` |
| 当前用户角色与功能可见性 | `GET /api/v1/features` + 后端 `access.Store` |
| 管理员身份 | JWT + `withAdmin` |
| 推荐配置、排期、审计 | 新增 SQLite 表（见 5.2） |
| 曝光与点击 | 新增 SQLite 事件表（见 5.2） |

### 5.2 数据表

`home_recommendation_slots`：

| 字段 | 说明 |
| --- | --- |
| id | 槽位 ID，UUID |
| feature_id | 功能注册表 ID |
| feature_kind | `tool` / `game`，由注册表推断 |
| enabled | 是否启用 |
| sort_order | 当天展示顺序 |
| starts_on / ends_on | 生效日期区间，可空 |
| weekdays | JSON 数组，每周生效日，可空表示全部 |
| title_override / description_override / cta_label_override | 文案覆盖，可空 |
| created_by / created_at / updated_by / updated_at | 审计基础字段 |

`home_recommendation_events`：

| 字段 | 说明 |
| --- | --- |
| id | 事件 ID |
| slot_id | 推荐位 ID |
| feature_id | 记录事件时的真实功能 ID，槽位删除后仍可统计 |
| user_id | 用户 ID |
| event_date | 事件日期（Asia/Shanghai） |
| event_type | `view` / `click` |
| created_at | 创建时间 |

唯一索引 `(user_id, event_date, slot_id, event_type)` 保证按日去重。

`home_recommendation_audit_log`：

| 字段 | 说明 |
| --- | --- |
| id | 日志 ID |
| admin_id | 操作管理员 |
| action | `create` / `update` / `delete` / `toggle` / `reorder` |
| slot_id | 槽位 ID |
| detail | JSON 变更摘要 |
| created_at | 时间 |

### 5.3 新增接口

| 方法 | 路径 | 权限 | 作用 |
| --- | --- | --- | --- |
| GET | `/api/v1/home/recommendations` | 可选登录 | 返回当天生效推荐位（按角色过滤），可传 `date` 预览 |
| POST | `/api/v1/home/recommendations/events` | 登录 | 上报 `view` / `click` 事件 |
| GET | `/api/v1/admin/home-recommendations` | 管理员 | 推荐位列表 + 当天生效摘要 |
| POST | `/api/v1/admin/home-recommendations` | 管理员 | 新建槽位（服务端校验真实功能） |
| PUT | `/api/v1/admin/home-recommendations/{slotID}` | 管理员 | 更新槽位 |
| DELETE | `/api/v1/admin/home-recommendations/{slotID}` | 管理员 | 删除槽位 |
| PUT | `/api/v1/admin/home-recommendations/reorder` | 管理员 | 批量调整顺序 |
| GET | `/api/v1/admin/home-recommendations/audit-log` | 管理员 | 审计记录 |
| GET | `/api/v1/admin/home-recommendations/stats` | 管理员 | 最近 30 天效果统计 |

公开接口响应示例（结构说明，字段含义以实际实现为准）：

```json
{
  "date": "2026-08-02",
  "source": "configured",
  "items": [
    {
      "slotId": "slot-01",
      "kind": "tool",
      "featureId": "smart-translation",
      "name": "智能翻译",
      "tagline": "AI 语境增强翻译",
      "icon": "translate",
      "accentColor": "#1f7b63",
      "route": "/tools/smart-translation",
      "ctaLabel": "进入工作台",
      "title": "智能翻译",
      "description": "AI 语境增强翻译",
      "sortOrder": 1
    }
  ]
}
```

服务端校验规则（新建/更新槽位时执行）：

1. `feature_id` 必须在注册表中存在。
2. 工具状态必须为 `available`，游戏状态必须为 `playable`。
3. 不得选择 `hiddenFromList: true` 的子入口。
4. 必须至少对 `normal / vip / svip / admin` 中的一种角色可见。
5. `startsOn <= endsOn`，`weekdays` 取值 1-7 且不重复。

## 6. 状态与异常处理

| 场景 | 处理 |
| --- | --- |
| 无启用槽位 | 首页返回 `source: "fallback"`，推荐最近使用工具或工具列表第一项 |
| 配置为 0 个推荐位 | 不构成合法配置：后台阻止保存；运行时兜底返回默认「打牌记分」并标注 fallback |
| 多个启用槽位 | 横向轮播展示，最多 3 张，不改变首页下方模块纵向位置 |
| 槽位引用的功能被隐藏 | 服务端跳过该槽位，后台列表标记「功能已失效」并提示重新选择 |
| 用户无权限 | 服务端过滤；后台校验面板显示当前角色可见性 |
| 接口失败 | 首页不渲染推荐区，保留布局空位，无本地 mock |
| 事件上报失败 | 静默重试一次，失败不阻断跳转 |
| 同日多个槽位 | 按 `sort_order` 展示，最多 3 个 |
| 文案覆盖为空 | 全部使用注册表真实字段 |

## 7. 埋点

| 事件 | 触发 | 参数 |
| --- | --- | --- |
| `home_recommendation_view` | 推荐模块可见 | date、slotId、kind、featureId、source |

## 8. 验收标准

### 8.1 功能验收

- [ ] 管理员可在后台新增、编辑、删除、排序「今日推荐」槽位。
- [ ] 槽位只能选择注册表中真实存在的 `available` 工具或 `playable` 游戏。
- [ ] 后台始终保留至少 1 个启用槽位；删除/关闭最后一个被阻止。
- [ ] 不配置任何推荐位时，首页默认展示「打牌记分」并标注 `source: "fallback"`。
- [ ] 首页展示内容与后台配置一致，名称、简介、CTA、图标、颜色、路由全部来自真实注册表或已保存的覆盖文案。
- [ ] 多个推荐位横向轮播，视觉、间距、自动播放、分页圆点与现有「精选功能」一致；首页下方模块位置不被撑开。
- [ ] 配置指定日期区间/星期后，首页按服务器日期正确生效。
- [ ] 隐藏、下架、角色不可见的功能不会出现在任何用户首页。
- [ ] 无配置时首页有真实兜底并标注来源，不渲染假数据。
- [ ] 曝光、点击事件写入数据库，后台效果概览展示最近 30 天真实数据。
- [ ] 所有配置变更写入审计日志。
- [ ] 320px / 390px / 430px 视口下推荐模块无文字溢出、无元素重叠。
- [ ] 深色模式同样适配，颜色取自现有 `appTheme`。

### 8.2 测试重点

- 后端单元测试：槽位 CRUD、注册表校验、日期排期、角色过滤、事件去重、审计写入。
- 接口测试：非管理员访问后台接口返回 `admin_required`；非法 feature_id 返回校验错误。
- 接口测试：删除/关闭最后一个启用槽位被拒绝；配置为 0 时公开接口返回 `card-score` 兜底。
- 前端测试：推荐模块空态、单卡、多卡、兜底、接口失败状态。
- 前端测试：轮播自动播放、手势滑动、页码圆点、减少动态效果，与现有 `FeaturedToolCarousel` 行为一致。
- 回归：现有首页搜索、最近使用、全部工具、游戏区块行为不变。

## 9. 实施范围

| 模块 | 内容 |
