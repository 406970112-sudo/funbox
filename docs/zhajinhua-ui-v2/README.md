# 炸金花记分 · UI V2

日期：2026-10-30。根据本轮反馈修正首页及积分池的视觉层级。玩法、回合提醒、比牌、喜钱、场间管理沿用 V1。此轮交付设计图与演示，没有修改小程序业务代码。

## 首页按现有页面调整

以 `miniprogram/pages/index/index.wxml` 和 `index.wxss` 为准，参考既有 `docs/mahjong-experience-v3/01-home-and-entry.png` 的首页：

- 保留 FunBox／棋牌记分与右侧账号入口。
- 保留“好友相聚，每局都算数。”及右上组合插画。
- 保留“选择牌局／不同玩法，一样清楚”的层级。
- 保留浅薄荷麻将卡、浅桃色炸金花卡的横向布局，文字左、插画右，维持原尺寸和间距。
- 删除整个记分原则／记分规则模块。
- 炸金花从“敬请期待”改为“已开放”，点击进入已设计的炸金花流程；底部导航保持原位置与风格。
- 根据随后反馈，删除首页底部“牌局服务正常”的文案及绿色状态点，不新增替代模块。

## 二维码与转发邀请

- 等候房间的二维码邀请卡内补充醒目的蓝色“转发邀请给好友”按钮，位于二维码／说明行下方；扫码与转发分别拥有清晰入口。
- 点按钮唤起微信原生转发，邀请指向当前房间并带房间邀请凭证。接收人填写昵称即可加入；场间加入仍由房主确认下场入座，不分摊之前的账。
- “点击放大”继续只用于放大二维码，避免将二维码点击与转发混为同一操作。
- 这次只修订首页服务状态行和等候房间转发入口，其他页面沿用。

## 积分池以金额和分数为主

- 金额为第一视觉层级，约 40–44px 逻辑字号；积分约 28–32px，醒目并列展示。小屏按可用宽度适当缩小，保持两项都可读。
- 纯数字白卡占满内容宽度，不保留插画列、不在积分池内使用扑克牌、骰子或大块筹码。
- 标题“公共积分池”和“1分=¥0.50”等换算率为辅助信息；不使用约等号。
- 跟注确认后分数与金额同时变化。动效仅在数值局部轻微强调及增量提示，不挤压数字、不改变按钮位置。
- 金额越大时可略增强一次性数值强调幅度，保持固定字号和卡片尺寸；关闭金额变化动效或减少动态时直接显示最终数值，不持续闪烁。
- 本人／他人回合、比牌弹层背景、封顶场景与设置中的预览都应用同一规则。其他页面原有插画保持。
