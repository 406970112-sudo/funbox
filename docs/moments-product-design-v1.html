PRODUCT DESIGN

让好友关系沉淀为真实内容流

朋友圈是 FunBox 的社交内容栏目：用户发布真实动态，好友点赞评论，互动通知实时同步，所有数据都可追溯。

核心流程

发布图文动态
服务端事务写入 SQLite
好友信息流可见
点赞评论实时通知

真实数据来源

users / friendships 真实账号与好友关系
moments / moment_media 真实动态与图片
likes / comments 真实互动
WebSocket + REST 真实通知同步
禁止 seed / mock / 硬编码回退

栏目入口

我的 > 社交 > 朋友圈
首页工具网格快捷入口
消息 Tab 合并互动未读红点

成功指标

≥99%发布成功率
≤1.2s首屏 p95
≥40%互动参与用户
100%无假数据验收

关键决策

空状态替代假数据

无好友、无动态、加载失败都显示真实空状态，绝不用示例内容填充。

事件只做刷新信号

WebSocket 事件只提示刷新，完整状态始终以 REST 返回的真实数据为准。
