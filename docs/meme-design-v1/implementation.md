# 表情包实施说明

2026-10-31，分支 `codex/meme-library`。按已批准方案实现；用户已要求提交并推送 main，推送本身不表示线上部署或微信小程序已发布。

## 已交付

- 小程序首页“发现更多”增加表情包整卡入口，**首页没有“我的藏图”入口**。模块内藏图与个人页收藏入口均可使用。
- 表情包分包 `miniprogram/packages/meme/`：全部图库、分类/标签搜索、静动筛选、排序、每页 36 项、历史搜索、分类列表、今日/本周/总榜、历史日榜、游客/账号收藏、最近浏览、详情、相关图片、预览、图片/页面分享与相册保存。
- Web `/tools/memes`：相同数据源与账号收藏；支持 `?imageId=...` 和 `?category=...`，桌面及手机布局。浏览器下载只提示已发起，不当作“保存成功”计入热度。
- Go `backend/internal/meme/`：原子快照、内容哈希去重、多分类与标签保留、版本化 cursor、受限媒体镜像、JWT 收藏、事件去重、站内榜单、管理员同步/状态/标签/屏蔽。
- 上游全量索引的本次实测：115 个分类、5,887 条记录、5,756 个去重资源。分类可见数量按去重图片计，故部分分类少于上游原始记录数；没有漏掉分类关系。

## 启动与媒体

沿用现有后端启动方式，从 `backend/` 执行 `go run ./cmd/api`。新配置：

```dotenv
MEME_WORKER_ENABLED=true
MEME_MEDIA_DIR=./storage/memes
SERVER_PUBLIC_BASE_URL=https://www.xwhub.cn
```

`DATABASE_PATH` 仍使用现有 SQLite。自动任务第一次启动同步完整索引，后台用 4 个工作协程镜像缩略图和原图；请求未镜像的图片时按需获取。每次启动会恢复状态/补齐镜像；北京时间 04:00 所属同步时段首次成功后不重复同步索引。封榜任务独立于媒体镜像执行，次日 00:10 后封榜，重启补齐遗漏的日榜。

API 的媒体 URL 为 `/api/v1/meme-media/{id}/{original|thumbnail}`，沿用已有 `/api/` 反向代理。目录在生产由两个部署脚本固定到 `$PERSISTENT_ROOT/data/memes`，不能落在 release 内。镜像只读取固定上游的已登记路径，拒绝重定向和非图片、过大/损坏图片，并检查原图 SHA256；不接受任意 URL 代理。媒体访问逐次校验上下架状态，不依靠公开静态目录绕过权限。

镜像最多同时进行 6 次上游下载；公共媒体预算为每 IP 每分钟 360 次，事件上报使用现有配置的独立限流 scope。索引读取失败、空/损坏快照、分类记录数不完整时保留旧快照。完整媒体原图约 515 MiB，另有缩略图；**全量索引可用不表示初次后台媒体镜像已经全部结束**。本次只在隔离的本地数据库和媒体目录进行真实数据联调，没有向生产写入测试数据。

Web 本地联调使用 `EXPO_PUBLIC_API_BASE_URL=http://127.0.0.1:<后端端口> npm run web`。小程序生产配置仍为既有 `https://www.xwhub.cn/api/v1`，未改成测试地址。实际模拟器联调使用 `/tmp/` 下的独立项目副本和本地测试 API，副本关闭开发期域名校验，生产项目配置保持原样。

## 业务口径

- 热度是本站有效详情浏览 × 1、新增收藏 × 3、保存成功 × 5；按北京时间和主体/图片/行为每日去重。每图至少 3 个主体，达标图片不足 10 个时只有“精选推荐，热度积累中”，无排名或假热度。
- 历史榜从本站首次导入后积累，不回溯构造上线前数据；已封榜保留算法版本和原位次，下架图不再返回媒体。
- 游客待同步收藏、已登录账号的失败操作和最近浏览分别隔离；游客合并绑定到稳定账号 ID，同账号换 Token 仍按序执行最新意图。下架/撤回的云收藏显示安全占位，可移除，不能预览或下载。
- 搜索只保证现有分类、文件标签及管理员补充标签匹配；无语义标签时不承诺理解任意自然语言。运营分组、OCR/向量检索、改字制作和整包导出仍为后续增强。
- 动画标记、源尺寸等目录元数据沿用上游；镜像核验实际 MIME、尺寸上限与完整首帧解码，不重新推断所有动画帧数。

## 管理 API

均需管理员 JWT：

```text
GET  /api/v1/admin/memes/status
POST /api/v1/admin/memes/sync
PUT  /api/v1/admin/memes/{id}    {"hidden":true}
PUT  /api/v1/admin/memes/{id}    {"labels":["开心","下班"]}
```

`hidden`、`labels` 可独立更新；本地屏蔽和补充标签不会被下一次上游同步覆盖。同步状态包含开始/成功时间、错误、镜像进度；重复任务有互斥保护。
