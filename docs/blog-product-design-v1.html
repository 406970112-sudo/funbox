真实数据红线： 正式功能的文章、标题、正文、封面、字数、点赞、评论、通知均来自真实数据库与 API，禁止 mock、seed 或硬编码演示数据。本设计稿中的封面与姓名仅用于展示布局。
PRODUCT DESIGN

让每个真实思考成为可被发现的长文

博客是 FunBox 的长文内容栏目：用户发布真实文章，选择完全公开、好友可见或仅自己可见，读者点赞、评论，互动通知实时同步。

核心流程

填写标题正文 / 选择可见范围
本地草稿自动保留
服务端事务写入 SQLite
公开 / 好友流可见与阅读
点赞评论实时通知

真实数据来源

users / friendships 真实账号与好友关系
blog_posts 真实文章与封面
服务端计算真实字数
likes / comments 真实互动
WebSocket + REST 真实通知同步
禁止 seed / mock / 硬编码回退

栏目入口

底部 Tab 新增“博客”
我的 > 社交 > 博客
首页工具网格快捷入口
消息 Tab 合并互动未读红点

成功指标

≥99%发布成功率
≤1.5s公开流首屏 p95
≥40%互动参与用户
100%无假数据验收

关键决策

三档可见范围

public 任何人可见，friends 仅好友可见，self 仅自己可见；作者可随时修改。

正文纯文本

正文按纯文本保留换行渲染，不执行 HTML；长度、敏感词与权限在服务端校验。

事件只做刷新信号

WebSocket 事件仅提示刷新，完整状态始终以 REST 返回的真实数据为准。
