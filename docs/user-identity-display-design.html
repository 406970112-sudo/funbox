Design Principles

方案要点

五条原则约束所有身份触点，避免「为了展示而展示」。

01
身份是状态
展示与权限严格一致，身份变更后立即刷新，不允许出现「显示 VIP 却没有权益」。
02
分层表达
常驻徽标负责认出来，身份卡负责看得懂，403 与社交触点负责用得上。
03
统一令牌
用户端与后台共用 identity.ts，颜色、图标、文案只维护一份。
04
克制展示
普通用户不常驻徽标；管理员不在社交场景公开；避免身份感泛滥。
05
变更可感知
管理员调整身份后，用户端用一次性提示告知变化，并刷新权限状态。
