# 公共首页主题修正 V2

用户反馈：首页麻将元素过重，需兼容炸金花及后续其他记分场景。

## 修正原则

首页代表 FunBox 记分工具，主视觉采用通用积分牌、正负分、对勾等元素。缩小装饰，优先展示场景入口。麻将牌、扑克牌、桌面和各自的氛围动效，只进入对应场景卡片与内页。

所有场景入口共用卡片尺寸、标题层级、图标大小、交互反馈和状态标签。已开放与敬请期待有明确区别，未开放的入口不能呈现为可创建牌局。

麻将的批量给分原则、结算方式等专属说明放入麻将页面。首页若展示通用提示，只描述跨场景成立的能力，不让某种玩法的规则代表整个产品。

## 后续扩展

新增场景沿用入口模板，设计配置包括场景标识、名称、图标、主题色、人数与规则摘要、开放状态；记分规则与房间流程仍由对应业务实现。视觉模板复用不表示可以直接共用麻将的计分逻辑。

当前只有麻将和炸金花两个入口，暂不增加搜索、分类或虚构未来玩法占位。入口变多时再按实际数量设计网格和分类，不预先堆复杂度。

优先级：公共首页去麻将化；保留麻将内页互动提案；炸金花开放时补充扑克牌主题和自己的计分流程。
