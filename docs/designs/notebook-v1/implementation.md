# 笔记本设计实施记录

日期：2026-11-07

## 已实施范围

- 5 个原生小程序页面：笔记列表、编辑、阅读详情、搜索、笔记本管理。
- 统一 nb-icon 组件：22 种圆角线性图标、4 种颜色，96×96 透明画布；图标容器统一以 flex 水平垂直居中。
- 按图册重排搜索筛选弹层、新建笔记本、更多操作、重命名和删除确认、加密管理、解锁和密码设置界面。
- 最新需求覆盖图册旧稿：移除图片、语音入口、附件展示、媒体 API、录音初始化、上传、下载与播放逻辑。编辑底栏仅保留清单和标签。
- 历史附件数据保留在后端；本次无数据删除迁移。网站端及后端兼容接口不在本次小程序改造范围。
- 编辑内容随正文增高；底栏避让键盘和安全区；短屏筛选与新建弹层支持滚动。

## 回归修复

- 从笔记本管理返回时更新可选分类，同时保留尚未保存的正文。
- 初次加载期间切换到后台再返回，重新加载并忽略旧请求。
- 收藏过程中隐藏页面，不再遗留按钮忙碌状态。
- 加密保存失败时保留加密意图，避免重试变成普通笔记。
