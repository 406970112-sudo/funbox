## 所有设计板共用提示词

Use case: ui-mockup. Create one high-fidelity Chinese WeChat mini-program design board for existing FunBox notebook feature, as part of a complete visual redesign package. The provided image is a STYLE REFERENCE ONLY, not an edit target: match its exact blue-white UI style, font hierarchy, soft corners, subtle shadows, roomy readable mobile density, native WeChat nav capsules and status bars, modest hero 3D notebook art. This board must be consistent with the reference and other boards. Primary #2d5bff, canvas #f5f7fa, white cards, dark ink #172139, muted #7b879c, coral #ff765e, divider #eaf0f7. All functional icons are ONE consistent rounded outline icon family, 24px canvas, 1.8px stroke, no emoji or illustrated/3D action icons. Small 3D notebook used only as optional decorative art. All Chinese must be accurate and readable. Landscape canvas, FOUR large complete front-facing mobile screens in a single row with slim subtle rounded frames, no perspective, generous image resolution, small top board header and a compact footer annotation strip. Screens must be large enough for readable text, take almost all available space. Each screen has native WeChat top status/nav and bottom safe area. No global tabbar inside the notebook subpackage. Outside screens pale blue-gray background. Header left italic cobalt FunBox with descriptive board title, right DESIGN V1. Small numbered labels above each screen. No invented unrelated features. Footer explains interactions in a few concise Chinese phrases. Do not draw arrows across screen content.
