# FunBox 微信小程序

这是 FunBox 原生微信小程序，代码位于 `miniprogram/`。当前已接入麻将打牌记分场景。

## 项目信息

- AppID：`wx1c056466c78d8934`
- 项目类型：原生微信小程序
- 后端：复用仓库根目录下的 `backend/` Go 服务
- 生产 API：`https://www.xwhub.cn/api/v1`

小程序不维护独立后端。账号、业务数据、文件上传等能力统一调用现有 FunBox 后端，接口和鉴权方式与 Web 前端保持一致。

## 使用微信开发者工具

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择当前 `miniprogram/` 文件夹。
3. 开发者工具会自动读取 `project.config.json` 中的 AppID。
4. 生产预览和发布前，在微信公众平台配置 `www.xwhub.cn` 的 request 合法域名。

## 本地联调

本地启动 Go 后端：

```bash
cd ../backend
go run ./cmd/api
```

然后把 `config/index.js` 中的 `API_BASE_URL` 临时改为：

```text
http://127.0.0.1:3000/api/v1
```

并在微信开发者工具中关闭域名校验。真机联调时应改为局域网可访问的 HTTPS 地址，不能使用电脑本机的 `127.0.0.1`。

## 目录说明

- `app.js` / `app.json` / `app.wxss`：小程序入口与全局配置
- `config/index.js`：统一后端地址和请求配置
- `utils/request.js`：统一请求封装，支持 Bearer Token
- `pages/`：小程序页面
- `project.config.json`：微信开发者工具项目配置

## 当前业务页面

- `pages/index/index`：首页牌局场景入口，麻将可用，炸金花显示“敬请期待”
- `pages/auth/index`：手机号注册、登录
- `pages/profile/index`：个人信息、最近牌局和功能反馈入口
- `pages/profile-settings/index`：更换头像、修改昵称和退出登录
- `pages/score/mahjong/index`：麻将房间创建、扫码优先加入和手动房间码加入弹层
- `pages/score/room/index`：房间等待、批量给分、实时分数、二次确认结算和结算结果

创建房间默认使用“老友局”房间名和“666666”房间密码，房间名和密码默认以轻量文字样式展示，点击文字或铅笔即可原位编辑，聚焦时显示淡蓝底线，无需弹窗或单独保存；昵称始终展示为可编辑输入框；已登录时默认反显账号昵称，游客则手动填写。创建时只输入一次房间密码，服务端只保存哈希。通过房间码加入时仍需输入密码，通过房主分享的邀请链接或小程序内扫码进入时只需填写昵称即可加入。游客身份不产生个人战绩；在房间中登录后，系统会把当前匿名参与者追溯绑定到账号，结算后即可在个人战绩中查看。创建麻将房间时不再设置每分金额或封顶，房间进行中也不显示暂定金额；房主散场结算时设置每分金额，默认 1 元/分。房主设备会在本地保存创建时输入的房间密码，仅供房主在邀请卡中查看；换设备或清除小程序缓存后无法恢复。

## 加入房间交互

“加入房间”首屏以“扫码加入”为主操作；“输入房间码加入”为次级入口，点击后打开底部弹层，填写 6 位房间码、4～6 位数字密码和昵称。弹层可关闭后继续填写，提交失败时保留输入并显示错误；提交中禁止重复加入。弹层跟随键盘高度调整，内容可滚动。

扫码与好友邀请链接共用邀请确认页，展示房间信息和邀请凭证已验证提示，只需确认昵称即可加入，不再要求输入房间码和密码。扫码取消不提示错误；无效邀请码和相机失败会在扫码入口附近提示。

## 微信平台配置

- 在微信公众平台配置 `https://www.xwhub.cn` 为 request 合法域名，并将 `wss://www.xwhub.cn` 配置为 socket 合法域名。
- 更换头像和上传反馈截图还需将 `https://www.xwhub.cn` 配置为 uploadFile 合法域名；头像支持 JPG、PNG，最大 3 MB。
- 邀请分享继续使用小程序页面路径；房主房间页同时从后端获取微信小程序码，因此小程序内“扫一扫加入”和微信外部“扫一扫”均可进入邀请房间。后端需配置 `WECHAT_MINIPROGRAM_APP_SECRET`，正式环境还需确保小程序房间页已经发布。
